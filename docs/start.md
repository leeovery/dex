# Start here

One question decides the path.

**Joining an existing instance** — the owner named an instance repo
(`owner/repo`), or you were given one:
fetch https://raw.githubusercontent.com/leeovery/dex/main/docs/setup.md
and follow it.

**Creating a new instance** — no instance repo exists yet:
fetch https://raw.githubusercontent.com/leeovery/dex/main/.claude/skills/new-dex-instance/SKILL.md
and follow it.

If it's unclear which applies, ask the owner.
