# Start here

Ask the owner: "Do you have an existing dex instance, or are we creating a
new one?"

**Existing** — ask which repo it is (a GitHub URL, `owner/repo`, or just
the name — whatever they give, work out the repo from it), then fetch
https://raw.githubusercontent.com/leeovery/dex/main/docs/setup.md
and follow it.

**New** — fetch
https://raw.githubusercontent.com/leeovery/dex/main/docs/create.md
and follow it.
