# Start here

Ask the owner: "Do you have an existing dex instance, or are we creating a
new one?"

**Existing** — ask for its repo (`owner/repo`), then fetch
https://raw.githubusercontent.com/leeovery/dex/main/docs/setup.md
and follow it.

**New** — fetch
https://raw.githubusercontent.com/leeovery/dex/main/.claude/skills/new-dex-instance/SKILL.md
and follow it.
